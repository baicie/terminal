# 设计系统

> 全局视觉与风格规范，实现时需统一遵守。

## 主题

- **默认主题**：深色模式（Dark Mode）。
- **背景层次**：
  - 主内容区：深炭灰/深紫灰，约 `#1A1B26`。
  - 侧栏：比主内容区略深，用于区分层级。
  - 卡片/面板：比主背景略亮，用于分组与悬停。

## 颜色

| 用途 | 描述 | 近似值/语义 |
|------|------|-------------|
| 主背景 | 深炭灰/深紫 | `#1A1B26` |
| 侧栏背景 | 略深于主背景 | 同色系更深 |
| 选中/激活 | 浅灰/浅蓝高亮 | 用于侧栏当前项、焦点 |
| 品牌/强调 | Ubuntu 橙等 | 如 `#E95420`，用于图标、主按钮 |
| 主操作按钮 | 蓝色 | 约 `#3D5AFE` |
| 成功/焦点 | 绿色 | 约 `#4CAF50`，用于边框、导入按钮 |
| 文字主色 | 白/浅灰 | 高对比 |
| 文字次要 | 小号、更灰 | 用于副标题、说明、时间戳 |

## 字体与排版

- **字体**：无衬线（Sans-serif），现代风格。
- **主文案**：白色或浅灰，保证在深色背景上可读。
- **次级信息**：较小字号、较灰颜色（如本地主机名、协议类型、时间等）。

## 图标

- **风格**：细线图标（thin-stroke line icons），单色。
- **例外**：品牌 Logo（如 Ubuntu 橙底）可保留原色。
- **位置**：侧栏与图标+文字并列；工具栏与按钮内联。

## 组件样式

- **圆角**：卡片、按钮、侧栏选中块使用圆角（rounded corners）。
- **阴影**：轻微阴影用于卡片与浮层，不抢眼。
- **间距**：主内容区留白充足，行距、列表间距统一（可用 `gap-*` 控制）。

## 交互状态

- **悬停**：卡片、列表项可有轻微背景或边框变化。
- **选中**：侧栏当前项用背景高亮（圆角块）；列表/卡片选中可用绿色或蓝色边框。
- **禁用**：按钮等使用低对比灰色。

## 与项目约定对应

- 实现时使用 **Tailwind** 语义色：`bg-primary`、`text-muted-foreground` 等。
- 不覆盖 shadcn/ui 组件的颜色变量，仅用 `className` 做布局与间距。
- 图标使用 **lucide-react**，与 AGENTS.md 中图标规范一致。
