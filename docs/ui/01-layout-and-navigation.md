# 全局布局与导航

> 应用整体为「顶栏 + 左侧导航 + 主内容区」结构，主内容区上方常有工具栏。

## 布局结构概览

```
┌─────────────────────────────────────────────────────────────────┐
│ 顶栏（窗口控制 / Vaults / 标签页 / 全局操作）                      │
├──────────┬──────────────────────────────────────────────────────┤
│          │ 主内容区工具栏（搜索、主操作按钮、视图切换等）            │
│ 左侧     ├──────────────────────────────────────────────────────┤
│ 导航     │                                                        │
│          │ 主内容区（Hosts / Terminal / SFTP / Logs 等）          │
│          │                                                        │
└──────────┴────────────────────────────────────────────────────┘
```

## 顶栏（Top Bar）

### 左侧

- **窗口控制**：macOS 风格红黄绿按钮（关闭、最小化、最大化）。
- **Vaults 下拉**：带云图标，用于切换/管理保险库（加密配置、同步等）。
- **标签页**：
  - 可存在多个标签：如「SFTP」「腾讯云4h4g1y」等。
  - 每标签表示一个会话或视图（SFTP 文件、某主机终端等）。
  - 右侧有「+」按钮，用于新建标签/会话。

### 右侧

- **搜索**：放大镜图标，全局搜索。
- **通知**：铃铛图标，系统或连接状态通知。
- **用户/账户**：头像或用户图标，可选「+」表示添加账户或协作。

## 左侧导航（Sidebar）

垂直排列，每项为「图标 + 文本」，点击切换主内容区视图。

| 项                  | 图标含义    | 功能                         |
| ------------------- | ----------- | ---------------------------- |
| **Hosts**           | 服务器/主机 | 主机列表、新建主机、快速连接 |
| **Keychain**        | 钥匙        | SSH 密钥、证书、密码等凭证   |
| **Port Forwarding** | 箭头/隧道   | SSH 隧道与端口转发规则       |
| **Snippets**        | 花括号 `{}` | 可复用命令片段与脚本         |
| **Known Hosts**     | 指纹/主机   | 已知主机指纹管理             |
| **Logs**            | 文档/列表   | 连接与操作日志               |

- **当前项**：背景为浅灰/浅蓝圆角块，与未选中项区分。
- **宽度**：较窄，以图标+文字不拥挤为准（约 60–80px 或略宽）。

## 主内容区通用模式

### 工具栏（主内容区顶部）

- **左侧**：
  - 全局搜索/连接输入框：占位符如「Find a host or ssh user@hostname...」，右侧可有「CONNECT」按钮。
  - 主操作按钮：如「NEW HOST」「NEW FORWARDING」「NEW SNIPPET」等，常带下拉箭头表示更多类型。
  - 次要操作：如「TERMINAL」「SERIAL」等。
- **右侧**：
  - 视图切换：网格/列表图标。
  - 筛选/组织：标签、分组、日历等图标。
  - 面板开关：详情面板、侧栏显隐等。

### 内容区

- 标题：如「Hosts」「Snippets」「Known Hosts」。
- 列表/网格/表格：依视图不同展示主机卡片、日志行、转发规则等。
- 空状态：无数据时显示图标 + 标题 + 简短说明 + 主操作引导。

## 路由与视图对应

- 侧栏项与路由一一对应（如 `/hosts`、`/keychain`、`/port-forwarding`、`/snippets`、`/known-hosts`、`/logs`）。
- 标签页与「当前打开的会话/视图」对应，可多开且独立状态。

## 实现提示

- 顶栏、侧栏、主内容区建议拆成布局组件（如 `layout/` 下），主内容区用 `<Outlet>` 或等价方式渲染子路由。
- 侧栏选中状态由当前路由决定（如 `NavLink` + `className` 高亮）。
- 标签页状态需全局管理（如 MobX store），便于多会话与关闭逻辑。
