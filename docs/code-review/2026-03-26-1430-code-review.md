## Rust 后端发现

### R-01: 字符串类型错误

**位置**: `src-tauri/src/ssh.rs`、`src-tauri/src/sftp.rs` 等多个文件

**严重程度**: 🟡 警告

**描述**: 所有 Tauri 命令返回 `Result<T, String>` 而非类型化错误枚举，导致错误信息传递到前端时丢失类型信息。

**证据**:

```rust:84:102:src-tauri/src/ssh.rs
#[tauri::command]
pub async fn ssh_connect(
    _state: tauri::State<'_, crate::state::SharedStateType>,
    host: String,
    port: u16,
    username: String,
    password: String,
) -> Result<String, String> {  // ⚠️ 字符串错误类型
    let session_id = format!("{}-{}:{}", username, host, port);

    let handle = create_and_authenticate(&host, port, &username, Some(&password), None)
        .await
        .map_err(|e| e.to_string())?;  // ⚠️ anyhow 错误转换为字符串
```

**影响**: 前端无法收窄错误类型，只能通过字符串匹配处理不同错误情况。

**建议**: 创建类型化错误枚举：

```rust
#[derive(Debug, Serialize)]
pub enum SshError {
    ConnectionFailed(String),
    AuthenticationFailed(String),
    SessionNotFound(String),
    InvalidInput(String),
}
```

### R-02: 任务 Spawn 未存储 JoinHandle

**位置**: `src-tauri/src/ssh.rs:316-346`、`src-tauri/src/local.rs:113-137`、`src-tauri/src/serial.rs:99-127`

**严重程度**: 🟡 警告

**描述**: `tokio::spawn` 使用时未存储 `JoinHandle`，导致无法：

1. 在关闭时等待任务完成
2. 检测任务 panic
3. 优雅取消任务

**证据**:

```rust:316:346:src-tauri/src/ssh.rs
    tokio::spawn(async move {
        loop {
            match channel.wait().await {
                Some(ChannelMsg::Data { data }) => {
                    // ...
                    let _ = app_clone.emit("ssh-data", output);
                }
                // ...
            }
        }
    });  // ⚠️ 未存储 JoinHandle — 窗口关闭时任务泄漏
```

**影响**: 即使前端窗口关闭，任务仍会继续运行，可能导致资源泄漏。

**建议**: 将 `JoinHandle` 存储在状态中，断开时中止：

```rust
// 在 state.rs 中
pub struct ShellTask {
    pub join_handle: tokio::task::JoinHandle<()>,
}

// 断开连接时
if let Some(task) = state.shell_tasks.lock().await.remove(&session_id) {
    task.join_handle.abort();
}
```

### R-03: 缺少输入验证

**位置**: 所有 Tauri 命令处理器

**严重程度**: 🟡 警告

**描述**: 命令参数直接使用而未验证，信任前端输入。

**证据**:

```rust:84:102:src-tauri/src/ssh.rs
pub async fn ssh_connect(
    _state: tauri::State<'_, crate::state::SharedStateType>,
    host: String,
    port: u16,  // ⚠️ 未验证：可能为 0 或超过 65535
    username: String,
    password: String,
) -> Result<String, String> {
```

**影响**: 无效输入可能导致运行时错误或意外行为。

**建议**: 在命令边界添加验证：

```rust
if host.is_empty() {
    return Err("Host cannot be empty".to_string());
}
if !(1..=65535).contains(&port) {
    return Err("Port must be between 1 and 65535".to_string());
}
```

### R-05: CSP 为 Null

**位置**: `src-tauri/tauri.conf.json:42`

**严重程度**: 🟡 警告

**证据**:

```json:42:43:src-tauri/tauri.conf.json
    "security": {
      "csp": null  // ⚠️ 未配置 CSP
    }
```

**影响**: 内容安全策略（CSP）有助于防止 XSS 攻击。缺少 CSP 会使应用程序更容易受到攻击。

**建议**: 添加限制性 CSP：

```json
{
  "csp": "default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'"
}
```

### T-02: 缺少 useCallback

**位置**: 多个组件

**严重程度**: 🟡 警告

**证据**:

1. `src/view/hosts/index.tsx:303-305`

```typescript
onKeyDown={e => {
  if (e.key === 'Enter') handleConnectBarSubmit()
}}  // ⚠️ 每次渲染创建新函数
```

2. `src/components/host-list/host-dialog.tsx:775-777`

```typescript
onKeyDown={e => {
  if (e.key === 'Enter' && password) onDecrypt()
}}
```

**影响**: 接收这些 props 的子组件在父组件渲染时不必要地重新渲染。

**建议**: 使用 `useCallback` 包装处理器：

```typescript
const handleKeyDown = useCallback(
  (e: React.KeyboardEvent) => {
    if (e.key === 'Enter' && password) onDecrypt()
  },
  [password, onDecrypt],
)
```

### T-03: Store 订阅模式

**位置**: 多个组件

**严重程度**: 🟡 警告

**证据**:

```typescript:89:96:src/view/hosts/index.tsx
useEffect(() => {
  void hostStore.loadHosts()
  void hostStore.loadGroups()
  // ...
}, [isTeamEnabled, currentTeam, hostStore, ...])  // ⚠️ hostStore 对象每次渲染都变化
```

**影响**: 如果 `hostStore` 是整个 store 对象（而非选择器），则会导致 effect 在每次渲染时都运行，因为对象引用发生变化。

**建议**: 使用具体选择器：

```typescript
// 改为：
const loadHosts = useHostStore(s => s.loadHosts)
const loadGroups = useHostStore(s => s.loadGroups)
```
