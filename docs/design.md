# Terminal - SSH/SFTP 客户端设计文档

> 参考 Termius 功能集设计

## 1. 产品概述

### 1.1 产品定位

一款现代跨平台的 SSH/SFTP 客户端，专注于提供安全、高效的远程服务器管理体验。

### 1.2 目标用户

- 开发者
- 系统管理员
- DevOps 工程师
- 网络工程师

---

## 2. 核心功能

### 2.1 连接管理

#### 2.1.1 主机 (Host)

| 功能 | 描述 | 优先级 |
|------|------|--------|
| SSH 连接 | 支持 SSH 协议连接远程服务器 | P0 |
| SFTP 连接 | 支持 SFTP 文件传输协议 | P0 |
| 主机地址 | 支持 IP 地址和域名 | P0 |
| 端口配置 | 自定义 SSH 端口 (默认 22) | P0 |
| 用户名 | 保存连接用户名 | P0 |
| 认证方式 | 密码 / SSH 密钥 / Agent 转发 | P0 |
| 端口转发 | 本地、远程、动态端口转发 | P1 |
| 主机链 | 通过跳板机连接 | P1 |
| IPv6 支持 | 支持 IPv6 地址连接 | P2 |

#### 2.1.2 组 (Group)

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 嵌套组 | 支持多级分组结构 | P1 |
| 继承设置 | 组内主机继承协议设置 | P1 |
| 批量操作 | 对组内主机批量执行命令 | P1 |

#### 2.1.3 收藏夹

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 收藏主机 | 快速访问常用主机 | P1 |
| 快速连接 | 一键连接已保存的主机 | P0 |

### 2.2 认证与安全

#### 2.2.1 认证方式

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 密码认证 | 用户名+密码登录 | P0 |
| SSH 密钥 | 使用私钥认证 | P0 |
| Agent 转发 | 使用本地 SSH Agent | P1 |
| 密钥生成 | 生成 Ed25519/RSA 密钥 | P1 |
| 证书认证 | SSH 证书认证 | P2 |
| 生物识别 | Face ID / Touch ID 保护密钥 | P2 |

#### 2.2.2 保险库 (Vault)

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 安全存储 | 加密存储凭证 | P1 |
| 端到端加密 | 本地加密，密钥不上传 | P1 |
| 跨设备同步 | 加密后同步到其他设备 | P2 |

#### 2.2.3 主机指纹

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 已知主机管理 | 保存主机指纹 | P1 |
| 指纹验证 | 首次连接验证指纹 | P1 |
| 指纹忽略 | 允许主机指纹变化 | P2 |

### 2.3 终端功能

#### 2.3.1 终端模拟

| 功能 | 描述 | 优先级 |

#### 2.3.3 终端操作

## 4. 数据结构

### 4.1 主机 (Host)

```typescript
interface Host {
  id: string;
  name: string;              // 显示名称
  hostname: string;         // IP 或域名
  port: number;             // 端口，默认 22
  username: string;         // 用户名
  authType: 'password' | 'key' | 'agent';
  password?: string;        // 加密存储
  privateKey?: string;      // 私钥内容
  groupId?: string;         // 所属组
  isFavorite: boolean;     // 是否收藏
  color?: string;          // 标记颜色
  tags?: string[];         // 标签
  portForwards: PortForward[];
  startupCommand?: string;  // 连接后自动执行
  environment?: Record<string, string>;
  createdAt: number;
  updatedAt: number;
}
```

### 4.2 组 (Group)

```typescript
interface Group {
  id: string;
  name: string;
  parentId?: string;        // 父组 ID，实现嵌套
  color?: string;
  inheritSettings: boolean; // 是否继承设置
  settings?: HostSettings;  // 继承的协议设置
  order: number;
}
```

### 4.3 Snippet

```typescript
interface Snippet {
  id: string;
  name: string;
  description?: string;
  script: string;
  packageId?: string;      // 所属包
  tags?: string[];
  variables?: Variable[];
}

interface SnippetPackage {
  id: string;
  name: string;
  description?: string;
}
```

### 4.4 端口转发

```typescript
interface PortForward {
  id: string;
  name: string;
  type: 'local' | 'remote' | 'dynamic';
  localPort?: number;
  localHost?: string;
  remotePort?: number;
  remoteHost?: string;
  active: boolean;
}
```

## 5. 技术架构

### 5.1 技术栈

| 层级 | 技术 |
|------|------|
| 前端框架 | React 19 + TypeScript |
| UI 组件库 | Ant Design |
| 状态管理 | MobX |
| 终端模拟 | xterm.js |
| 后端框架 | Tauri 2.x (Rust) |
| SSH 库 | russh |
| 数据库 | SQLite (tauri-plugin-sql) |
| 构建工具 | Vite |

### 5.2 模块划分

```
src/
├── view/                    # 页面组件
│   ├── terminal/            # 终端页面
│   ├── sftp/                # SFTP 页面
│   ├── hosts/               # 主机管理页面
│   └── settings/            # 设置页面
├── components/              # 可复用组件
│   ├── Terminal/            # 终端组件
│   ├── Sftp/               # SFTP 组件
│   ├── HostList/           # 主机列表
│   └── Connection/         # 连接管理
├── store/                   # MobX 状态
│   ├── host.ts             # 主机状态
│   ├── terminal.ts         # 终端状态
│   └── settings.ts         # 设置状态
├── services/                # 业务逻辑
│   ├── ssh.ts              # SSH 连接服务
│   ├── sftp.ts             # SFTP 服务
│   └── storage.ts          # 数据存储
└── utils/                   # 工具函数
```
