## 四、优先级排序建议

### 高优先级 (P0)

1. **SSH 密钥认证完善** - 当前 MVP 已支持密码，密钥认证需完善
2. **SFTP 文件传输** - 核心功能，用户刚需
3. **本地终端** - 支持本地 shell 连接
4. **命令历史** - 提升用户体验

### 中优先级 (P1)

1. **端口转发** - 高级用户需求
2. **分屏模式** - 提升多任务效率
3. **Snippet** - 常用脚本快速执行
4. **主题系统** - 完善用户体验

### 低优先级 (P2)

1. **Vault 加密** - 安全增强
2. **多工作区** - 项目隔离
3. **命令面板** - 快捷操作
4. **跨设备同步** - 云端同步
