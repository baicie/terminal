# macOS Daily Driver 验收 — 最小人工清单

- 目标源码：`main = 13e9d96`（功能合并 `e234091`）
- 适用构建：本目录旁的 QA 包（见 `qa-build.md` 的记录）
- 用途：让用户用**最少的点击**判断这份构建能否替代 Tabby

> 7 天记录表在文末。**未亲自做过的项一律留空，不写 PASS。**
> 本文档不含任何实测结果 —— 它的存在本身不代表任何一项通过。

## 0. 开始前（约 2 分钟）

1. **备份现有数据**（如果这台机器上已有 Terminal 在存主机）
   ```
   设置 → 存储 → 导出
   同时复制 `~/Library/Application Support/com.baicie.termius/terminal.db` 与 `vault.json`
   ```
   两者必须一起备份：只有 db 会得到「有引用但没有秘密」的主机。

2. **确认 Tabby 数据不动**。Terminal 与 Tabby 各自一套数据，没有同步；
   验收期间 Tabby 照常可用，随时可回退。

3. **记录一份对照清单**：当前 Tabby 里的主机数量与名称（截图或手抄）。

## 10. 回退方案

任何时候想退回 Tabby：

1. 关闭 Terminal；
2. 打开 Tabby —— **它的数据全程未被改动**，直接可用；
3. Terminal 的数据在独立目录，不需要清理。

**不要**为了「两边一致」手工同步数据库 —— 那是两套 schema。

若 Terminal 本身出问题需要恢复：

```
关闭应用
把备份的 terminal.db 与 vault.json 放回 ~/Library/Application Support/com.baicie.termius/
重新启动（db_recovery 会检测迁移标记，必要时自动恢复快照）
用原主密码解锁
```
